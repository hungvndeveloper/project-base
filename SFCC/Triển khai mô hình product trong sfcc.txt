Triển khai Mô Hình Product trong Business Manager của SFCC
Trong Salesforce Commerce Cloud (SFCC), Business Manager (BM) là công cụ chính để quản lý dữ liệu sản phẩm. Dưới đây là hướng dẫn chi tiết về cách triển khai mô hình Base Product – Variant Products – Variation Attributes trong Business Manager.

1. Cấu Trúc Product trong SFCC
       SFCC sử dụng 3 loại sản phẩm chính:

       Loại sản phẩm	                     Mô tả
       Base Product (Master Product)	Sản phẩm chính, không thể mua, dùng để nhóm biến thể.
       Variation Product	              Sản phẩm biến thể (có SKU, giá, kho hàng).
       Variation Attributes	              Các thuộc tính giúp phân biệt biến thể (Màu sắc, Kích thước).
2. Các bước triển khai trong Business Manager
       Bước 1: Tạo Base Product (Master Product)
       📌 Điều hướng: Business Manager → Merchant Tools → Products → Products.
              Nhấn New để tạo sản phẩm mới.
              Chọn Master Product làm kiểu sản phẩm.
              Điền các thông tin cơ bản:
                     Product ID: (Ví dụ: NIKE_AIR_MAX)
                     Name: "Nike Air Max 2024"
                     Brand: "Nike"
                     Category: Chọn danh mục phù hợp
                     Online Flag: ✅ Bật để kích hoạt sản phẩm
                     Lưu lại.
       Bước 2: Tạo Variation Attributes
       📌 Điều hướng: Business Manager → Merchant Tools → Products → Variation Attributes.
              Nhấn New và tạo các thuộc tính như:
                     Color
                     Size
              Mỗi thuộc tính có thể có nhiều giá trị:
                     Color: Red, Blue, Green
                     Size: S, M, L, XL
              Lưu lại.
       Bước 3: Gán Attributes vào Master Product
       📌 Điều hướng: Mở sản phẩm Master Product (NIKE_AIR_MAX).
              Chọn tab Variations.
              Trong phần Variation Attributes, nhấn Assign và chọn các attributes (Color, Size).
              Nhấn Apply.
       Bước 4: Tạo Variant Products
       📌 Điều hướng: Mở Master Product (NIKE_AIR_MAX).
              Chọn tab Variants.
              Nhấn New để tạo các sản phẩm biến thể, ví dụ:
                     NIKE_AIR_MAX_RED_M
                     NIKE_AIR_MAX_RED_L
                     NIKE_AIR_MAX_BLUE_M
              Điền các thông tin:
                     Price: (Ví dụ: $199.99)
                     Stock: (Ví dụ: 50)
                     Online Flag: ✅
              Nhấn Save.
       Bước 5: Kiểm tra Hierarchy
       📌 Điều hướng: Mở lại Master Product (NIKE_AIR_MAX).
              Vào tab Variations để xem danh sách biến thể.
              Kiểm tra thuộc tính, giá, kho hàng của từng biến thể.
       Bước 6: Cấu hình Hiển thị Variant trên Storefront
       📌 Điều hướng: Merchant Tools → Catalogs → Storefront Catalog.
              Tìm sản phẩm Nike Air Max.
              Đảm bảo thuộc tính biến thể hiển thị đúng.
              Truy cập Storefront và kiểm tra cách hiển thị trên website.

       ✅ Base Product chứa thông tin chung của sản phẩm.
       ✅ Variation Attributes giúp quản lý các biến thể.
       ✅ Variant Products có SKU, giá, kho hàng riêng biệt.
       ✅ Business Manager hỗ trợ quản lý tất cả các bước trên giao diện.

CREATE TABLE products (
  id int NOT NULL,
  name varchar(255) DEFAULT NULL,
  image text,
  description text,
  brand_id int NOT NULL,
  category_id int NOT NULL,
  created_at datetime DEFAULT CURRENT_TIMESTAMP,
  updated_at datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  stock int DEFAULT '0' COMMENT 'Số lượng tồn kho',
  rating decimal(2,1) DEFAULT NULL COMMENT 'Đánh giá sản phẩm (0-5)',
  total_ratings int DEFAULT '0' COMMENT 'Tổng số lượt đánh giá',
  total_sold int DEFAULT '0' COMMENT 'Tổng số lượng đã bán',
  price decimal(12,2) DEFAULT NULL,
  old_price decimal(12,2) DEFAULT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;
2. bảng attributes:
CREATE TABLE attributes (
  id int NOT NULL,
  name varchar(255) DEFAULT NULL,
  created_at datetime NOT NULL,

  updated_at datetime NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;

CREATE TABLE variants (
