Tôi sẽ giải thích chi tiết về BEM và best practices khi triển khai HTML/CSS dựa trên code mẫu của bạn.
    1. BEM (Block Element Modifier) là gì?
        BEM là một phương pháp đặt tên class CSS với cú pháp:
            - Block: Thành phần độc lập (ví dụ: header, search)
            - Element: Phần tử con của block (headerlogo, search_input)
            - Modifier: Biến thể của block/element (headerbutton--user)
        Cú pháp:
            block__element--modifier
    2. Ví dụ BEM trong code của bạn:
        <!-- Block: header -->
        <header class="header">
            <!-- Element: header__content -->
            <div class="header__content">
                <!-- Element: header__logo -->
                <img class="header__logo">
                
                <!-- Block mới: search -->
                <div class="search header__search">
                    <!-- Element của search -->
                    <i class="search__icon"></i>
                    <input class="search__input">
                </div>

                <!-- Element với modifier -->
                <button class="header__button header__button--user">
        </header>
    3. Best Practices khi viết HTML/CSS:
        - Semantic HTML:
            Sử dụng các thẻ có ý nghĩa: <header>, <nav>, <main>, <footer>
            Tránh lạm dụng <div> khi có thể dùng thẻ semantic
        - Accessibility:
            <!-- Thêm aria-label cho các button -->
            <button class="header__button" aria-label="User account">
                <i class="fa-regular fa-user"></i>
            </button>

            <!-- Thêm alt cho hình ảnh -->
            <img class="header__logo" alt="Coolmate logo" src="...">
        - Cấu trúc CSS:
            /* Tổ chức CSS theo thứ tự */
            .header {
                /* 1. Positioning */
                position: relative;
                
                /* 2. Box Model */
                padding: 20px;
                margin: 10px;
                
                /* 3. Visual */
                background: white;
                
                /* 4. Typography */
                font-size: 16px;
                
                /* 5. Misc */
                transition: all 0.3s;
            }
        - Mobile First:
            /* Mobile first */
            .header__menu {
                display: none; /* Mặc định ẩn trên mobile */
            }

            /* Desktop styles */
            @media (min-width: 768px) {
                .header__menu {
                    display: flex;
                }
            }
    4. Cải thiện code hiện tại:
        - Tách components:
            <!-- Tách search thành component riêng -->
            <div class="search">
                <i class="search__icon"></i>
                <input class="search__input" type="text">
                <button class="search__button" aria-label="Search">
            </div>
        - Thêm các thuộc tính accessibility:
            <nav class="header__nav" role="navigation">
            <button class="header__button" aria-label="Toggle menu">
            <input class="search__input" aria-label="Search products" type="text">
        - Tổ chức file CSS:
            styles/
            ├── base/
            │   ├── reset.css
            │   └── typography.css
            ├── components/
            │   ├── header.css
            │   └── search.css
            └── main.css
    5. Lưu ý quan trọng:
        - Luôn giữ tính nhất quán trong việc đặt tên
        - Tránh selector quá sâu (không quá 3 cấp)
        - Tách code thành các component nhỏ, tái sử dụng
        - Ưu tiên mobile-first và responsive design
        - Luôn nghĩ đến accessibility khi code
        - Comment code khi cần thiết để giải thích logic phức tạp

vậy nếu như có nhiều cấp lồng nhau thì làm sao để biết đâu là block, element, modifier

=> Tôi sẽ giải thích cách xác định Block, Element và Modifier trong các trường hợp lồng nhau phức tạp.
    1. Nguyên tắc cơ bản:
        - Block là thành phần độc lập, có thể tái sử dụng
        - Element là thành phần phụ thuộc vào Block
        - Modifier là biến thể của Block hoặc Element
    2. Ví dụ với menu phức tạp:
        <nav class="menu">                              <!-- Block: menu -->
            <ul class="menu__list">                     <!-- Element của menu -->
                <li class="menu__item">                 <!-- Element của menu -->
                    <a href="#" class="menu__link">     <!-- Element của menu -->
                        <span class="menu__text">       <!-- Element của menu -->
                            Products
                        </span>
                        <div class="submenu">           <!-- Block mới: submenu (KHÔNG phải menu__submenu) -->
                            <ul class="submenu__list">  <!-- Element của submenu -->
                                <li class="submenu__item submenu__item--active"> <!-- Element với modifier -->
                                    <a href="#" class="submenu__link">
                                        Sport
                                    </a>
                                </li>
                            </ul>
                        </div>
                    </a>
                </li>
            </ul>
        </nav>
3. Các trường hợp phức tạp:
    - Card với nhiều thành phần:
        <form class="form">                       <!-- Block: form -->
            <div class="form__group">             <!-- Element của form -->
                <label class="form__label">       <!-- Element của form -->
                    Email
                </label>
                
                <div class="input">               <!-- Block mới: input -->
                    <input class="input__field input__field--error"> <!-- Element với modifier -->
                    <span class="input__icon">    <!-- Element của input -->
                        <i class="fa fa-envelope"></i>
                    </span>
                    <div class="tooltip">         <!-- Block mới: tooltip -->
                        <span class="tooltip__text">  <!-- Element của tooltip -->
                            Invalid email
                        </span>
                    </div>
                </div>
            </div>
        </form>
    - Form phức tạp:
        <form class="form">                       <!-- Block: form -->
            <div class="form__group">             <!-- Element của form -->
                <label class="form__label">       <!-- Element của form -->
                    Email
                </label>
        
                <div class="input">               <!-- Block mới: input -->
                    <input class="input__field input__field--error"> <!-- Element với modifier -->
                    <span class="input__icon">    <!-- Element của input -->
                        <i class="fa fa-envelope"></i>
                    </span>
                    <div class="tooltip">         <!-- Block mới: tooltip -->
                        <span class="tooltip__text">  <!-- Element của tooltip -->
                            Invalid email
                        </span>
                    </div>
                </div>
            </div>
        </form>
4. Quy tắc xác định Block mới:
    - Khi nào tạo Block mới:
        - Thành phần có thể tái sử dụng ở nhiều nơi
        - Thành phần hoạt động độc lập
        - Thành phần có logic/style riêng biệt
    - Khi nào dùng Element:
        - Phần tử phụ thuộc vào Block cha
        - Không thể tồn tại độc lập
        - Chỉ sử dụng trong phạm vi Block
5. Tips để tránh nhầm lẫn:
    - Không lồng BEM:
        /* KHÔNG NÊN */
        .block__element1__element2 { }

        /* NÊN */
        .block__element1 { }
        .block__element2 { }
    - Tạo Block mới khi cần:
        <!-- KHÔNG NÊN -->
        <div class="card__header__title__text">

    <!-- NÊN -->
        <div class="card__header">
            <h2 class="card__title">
                <span class="text">  <!-- Block mới nếu text có style riêng -->
    - Modifier rõ ràng:
        <!-- KHÔNG NÊN -->
        <div class="card card__header--blue">

        <!-- NÊN -->
        <div class="card card--blue">
            <div class="card__header">
    - Kiểm tra tính độc lập:
        - Nếu có thể di chuyển component đến vị trí khác mà vẫn hoạt động → Block mới
        - Nếu không thể tách rời khỏi parent → Element
