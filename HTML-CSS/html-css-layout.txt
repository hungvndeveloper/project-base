1. quy tắc nhóm hóa:
    - Các phần tử liên quan được nhóm lại trong một container (div, ul, a).
    - Mục đích là tạo ra một cấu trúc HTML rõ ràng, dễ hiểu và dễ quản lý.

🔰 BEM là gì?
    - Block – phần tử độc lập, có thể tái sử dụng (ví dụ: header, menu, card).
    - Element – phần tử con, phụ thuộc vào block (ví dụ: menu__item, card__title).
    - Modifier – trạng thái hoặc biến thể của block/element (ví dụ: button--primary, menu__item--active).
✅ Tips Best Practice với BEM
    - Block rõ ràng, không quá dài: hero, features, footer.
    - Element luôn gắn block: hero__title, footer__link.
    - Modifier chỉ dùng để thay đổi trạng thái hoặc kiểu: button--primary, nav__link--active.
    - Không lồng nhiều class BEM không liên quan nhau (tránh .hero__title.feature__title).
Mẹo thêm
    - Nếu bạn có nhiều layout khác nhau (auth, dashboard, landing), 
      bạn có thể đặt class="layout layout--auth" hoặc page--dark cho body để thay đổi toàn cục.
    - page__wrapper cũng là nơi hợp lý để bọc <div id="app"> nếu bạn tích hợp với Vue/React.
📌 Một số best practices
    Tình huống	                                    Hành động
    Thay đổi layout toàn bộ (auth, dashboard)	    Dùng page--auth, page--dashboard modifier
    Chia layout 2 cột	                            Áp dụng layout trong page__wrapper hoặc main-content__layout
    Thêm wrapper trong từng block	                Dùng block__wrapper (ví dụ hero__wrapper) khi cần bọc layout riêng
    Responsive?	                                    Đặt media queries hoặc dùng CSS utility (tailwind, hoặc custom mixins)

🧠 Giải thích tổ chức BEM trong ví dụ
    Block	        Ý nghĩa
    header	        Header của trang
    nav	            Menu điều hướng
    hero	        Phần giới thiệu chính (hero banner)
    features	    Phần hiển thị tính năng
    feature-card	Từng tính năng cụ thể (card)
    sidebar	        Cột bên, tin tức
    footer	        Chân trang
    button	        Nút bấm tái sử dụng

    Mỗi block có container riêng: block__container để căn chỉnh và giới hạn chiều rộng, dễ responsive.


==============================================================================================================
🔹 container
    - Ý nghĩa: Là phần tử chứa nội dung chính của trang hoặc một khối nội dung cụ thể.
    - Chức năng:
        - Giới hạn chiều rộng của nội dung (ví dụ: max-width: 1200px;).
        - Căn giữa nội dung (thường dùng margin: 0 auto;).
        - Định hình layout, tạo lề hai bên.
    - Thường dùng trong: Bootstrap, Tailwind, hoặc các thiết kế responsive.
    - Ví dụ:
        <div class="container">
            <h1>Trang chủ</h1>
            <p>Đây là nội dung chính.</p>
        </div>
    CSS:
        .container {
            max-width: 1200px;
            margin: 0 auto;
            padding: 0 20px;
        }
🔹 wrapper
    - Ý nghĩa: Là phần tử bọc xung quanh một nhóm các phần tử liên quan, không nhất thiết là phần nội dung chính.
    - Chức năng:
        - Gom nhóm các phần tử lại với nhau.
        - Có thể dùng để định vị, canh chỉnh, hoặc áp dụng style chung cho nhóm đó.
    - Thường bao ngoài container hoặc các khối cụ thể như header, footer, form...
    - Ví dụ:
        <div class="wrapper">
            <div class="container">
                <h1>Trang chủ</h1>
                <p>Đây là nội dung chính.</p>
            </div>
        </div>
    CSS:
        .wrapper {
            background-color: #f9f9f9;
            padding: 40px 0;
        }
✅ Tổng kết so sánh
    Tên	Vai trò chính	    Vị trí thường dùng
    container	            Giới hạn, căn chỉnh và chứa nội dung chính	Bao quanh nội dung chính
    wrapper	                Bọc ngoài các phần tử, giúp bố trí, định dạng chung	Bao quanh container hoặc phần tử nhóm

Tuyệt vời, chúng ta cùng phân tích tổng thể layout đã làm theo chuẩn BEM và đưa ra hướng sử dụng linh hoạt về sau cho các framework như React hoặc Vue nhé.

✅ 1. Cấu trúc tổng thể của layout
<body class="page">
  └── <div class="page__wrapper">               (Khung bao toàn bộ nội dung)
        ├── <header class="header">            (Phần đầu trang)
        │     └── .header__container
        │         └── .header__logo
        │         └── .header__nav (.nav)
        │             └── .nav__list
        │                 └── .nav__item > .nav__link
        ├── <main class="main-content">        (Nội dung chính)
        │     ├── <section class="features">   (Nội dung nổi bật)
        │     │     └── .features__container
        │     │         └── .features__list > .features__item (.feature-card)
        │     └── <aside class="sidebar">      (Thanh bên)
        │           └── .sidebar__container > .sidebar__list
        └── <footer class="footer">            (Chân trang)
              └── .footer__container
                  └── .footer__copyright
                  └── .footer__socials > .footer__link

🧱 2. Vai trò các phần tử chính
    Thành phần	                Mô tả
    body.page	                Áp dụng font, màu nền chung. Không dùng để layout.
    .page__wrapper	            Khung chính bao tất cả nội dung, giúp căn giữa, giới hạn chiều rộng, đảm bảo layout.
    .header, .footer	        Thành phần ngoài cùng – thường cố định ở đầu/cuối trang.
    .main-content	            Vùng chính chia làm hai cột: .features và .sidebar.
    .features	                Nội dung chính cần nổi bật: tính năng, bài viết...
    .sidebar	                Tin mới, liên kết phụ, danh mục...

🧩 3. Ưu điểm của layout này
    ✅ Tuân thủ BEM: rõ ràng, dễ mở rộng, dễ đọc.
    ✅ Responsive sẵn: có chia layout cho desktop/tablet/mobile.
    ✅ Linh hoạt: dễ dàng tách ra component trong React/Vue hoặc đổi block/layout.

⚛️ 4. Khi dùng với React / Vue
    a. Không cần đổi class
        - Bạn vẫn giữ nguyên class BEM như vậy để đảm bảo tính thống nhất. Nhưng cần lưu ý:
        - Trong React: dùng className thay vì class.
        - Trong Vue: dùng :class hoặc v-bind:class nếu muốn ràng buộc động.

    b. Thêm các class linh hoạt
        Trường hợp muốn…	                                Cách làm
        Layout khác nhau giữa trang home và trang con	    Thêm modifier class ở .page, ví dụ: class="page page--home" hoặc page--about
        Ẩn sidebar ở một số trang	                        Thêm sidebar--hidden hoặc kiểm tra logic render trong React/Vue
        Header/footer thay đổi giao diện	                Dùng class như header--dark, footer--minimal
        Một block hiển thị theo trạng thái	                VD: feature-card--active, nav__link--disabled

    Bạn có thể quy định thêm các modifier class để điều chỉnh UI trong từng ngữ cảnh cụ thể. BEM rất mạnh ở điểm này.

📝 5. Lưu ý khi mở rộng layout
    ⚠️ Không nên trộn id và class để xử lý style, hãy trung thành với class BEM.
    💡 Nếu layout có 3 cột, dùng thêm .layout--3col, sau đó xử lý CSS theo modifier.
    🧩 Có thể tạo các components riêng: Header, Footer, Sidebar, FeatureList…
    📦 Nếu dùng SCSS, có thể tổ chức như:
        /scss/
            ├── base/
            ├── components/
            │    ├── _header.scss
            │    ├── _sidebar.scss
            │    └── _feature-card.scss
            ├── layout/
            │    ├── _wrapper.scss
            │    └── _page.scss
            └── main.scss
📌 Kết luận
    ✅ Bạn đang có một layout chuẩn mực, sạch và dễ tái sử dụng.
    ✅ Dùng tốt cho cả HTML thuần lẫn React/Vue mà không cần thay đổi lớn.
    ✅ Rất phù hợp để làm khung layout khởi đầu cho mọi dự án web.
