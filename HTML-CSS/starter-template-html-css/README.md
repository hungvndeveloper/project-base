# HTML & CSS Starter Template

A minimal, semantic, mobile‑first template to get you started quickly with any static website.

## Folder Structure

```
html-css-template/
├── index.html
├── css/
│   └── style.css
└── README.md
```

## Usage

1. **Download** and unzip the folder or clone the repo.
2. Open `index.html` directly in your browser, or better:
   - Install the **Live Server** extension (VS Code) and run the project to get auto‑reload.
3. Start editing `index.html` and `css/style.css`. The BEM naming and mobile‑first CSS are ready for you.
4. Add images to an `assets/` folder (create if needed) and reference them with relative paths.

## Features

- Semantic HTML5 structure (`header`, `main`, `section`, `footer`).
- BEM class naming convention.
- Global reset & `box-sizing: border-box`.
- Mobile‑first, responsive layout via CSS Grid & Flexbox.
- Utility classes for quick spacing & text alignment.
- Well‑commented code to guide beginners.

Happy coding!
