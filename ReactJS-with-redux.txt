Để giúp bạn dễ dàng tiếp cận với Context và Redux Toolkit, mình sẽ giải thích từng cái một cách đơn giản và sau đó chỉ cho bạn cách triển khai chúng trong ứng dụng React.

1. Context API trong React
    Context API là một cách để chia sẻ dữ liệu giữa các component mà không cần phải truyền props qua nhiều lớp component. Nó hữu ích khi bạn có một giá trị hoặc trạng thái cần được chia sẻ rộng rãi trong ứng dụng mà không cần phải truyền qua props giữa các component cha-con.

    - Lý do dùng Context:

        - Khi bạn có các dữ liệu hoặc trạng thái cần được chia sẻ toàn cục trong ứng dụng (ví dụ: theme, user data, ngôn ngữ, v.v).
        - Giảm thiểu việc phải truyền props qua nhiều component.

    - Các bước triển khai Context API:

        - Tạo Context: Đầu tiên, bạn cần tạo một Context để chứa dữ liệu bạn muốn chia sẻ.
        - Provider: Sử dụng <Context.Provider> để bao bọc các component và cung cấp dữ liệu cho chúng.
        - Consumer hoặc useContext Hook: Các component con có thể sử dụng useContext để lấy dữ liệu từ Context.

    - Ví dụ triển khai Context API:
        // 1. Tạo Context
        import React, { createContext, useState, useContext } from 'react';

        // Tạo Context cho User
        const UserContext = createContext();

        // 2. Tạo Provider để cung cấp dữ liệu
        export const UserProvider = ({ children }) => {
        const [user, setUser] = useState({ name: 'John Doe', age: 30 });

        return (
            <UserContext.Provider value={{ user, setUser }}>
            {children}
            </UserContext.Provider>
        );
        };

        // 3. Sử dụng Context trong component con
        const UserProfile = () => {
        const { user } = useContext(UserContext);  // Lấy dữ liệu từ Context

        return <div>User Name: {user.name}</div>;
        };

        // 4. Sử dụng Provider trong ứng dụng
        const App = () => (
            <UserProvider>
                <UserProfile />
            </UserProvider>
        );

        export default App;
2. Redux Toolkit
    - Redux là một thư viện quản lý trạng thái toàn cục trong ứng dụng. Redux Toolkit là một cách đơn giản và mạnh mẽ để làm việc với Redux, giúp giảm thiểu việc viết boilerplate code.
    - Lý do dùng Redux:
        - Khi ứng dụng của bạn trở nên phức tạp và cần quản lý nhiều trạng thái, việc sử dụng Redux giúp bạn tổ chức và quản lý trạng thái một cách rõ ràng và hiệu quả.
        - Redux Toolkit giúp bạn dễ dàng cài đặt và giảm thiểu lỗi trong việc quản lý trạng thái.
    - Các bước triển khai Redux Toolkit:
        - Tạo Store: Store là nơi chứa toàn bộ trạng thái của ứng dụng.
        - Tạo Slice: Slice là nơi bạn định nghĩa reducer (xử lý trạng thái) và action (thao tác thay đổi trạng thái).
        - Cung cấp Store: Sử dụng <Provider> để cung cấp store cho ứng dụng.
        - Sử dụng Dispatch: Các component có thể sử dụng useDispatch để gửi action và useSelector để lấy dữ liệu từ store.
    - Ví dụ triển khai Redux Toolkit:
        - Cài đặt Redux Toolkit:
            npm install @reduxjs/toolkit react-redux
        - Tạo Slice và Store:
            // src/store.js
            import { configureStore, createSlice } from '@reduxjs/toolkit';

            // Tạo Slice cho user
            const userSlice = createSlice({
            name: 'user',
            initialState: { name: 'John Doe', age: 30 },
            reducers: {
                updateUser: (state, action) => {
                state.name = action.payload.name;
                state.age = action.payload.age;
                },
            },
            });

            export const { updateUser } = userSlice.actions;

            const store = configureStore({
            reducer: {
                user: userSlice.reducer,
            },
            });

            export default store;

    - Cung cấp Store cho ứng dụng:
        // src/index.js
        import React from 'react';
        import ReactDOM from 'react-dom';
        import { Provider } from 'react-redux';
        import App from './App';
        import store from './store';

        ReactDOM.render(
        <Provider store={store}>
            <App />
        </Provider>,
        document.getElementById('root')
        );
    - Sử dụng Redux trong Component:
        // src/App.js
        import React from 'react';
        import { useDispatch, useSelector } from 'react-redux';
        import { updateUser } from './store';

        const UserProfile = () => {
        const user = useSelector((state) => state.user);  // Lấy dữ liệu từ Redux Store
        const dispatch = useDispatch();  // Để gửi action

        const handleChangeName = () => {
            dispatch(updateUser({ name: 'Jane Doe', age: 25 }));
        };

        return (
            <div>
            <p>User Name: {user.name}</p>
            <p>User Age: {user.age}</p>
            <button onClick={handleChangeName}>Update User</button>
            </div>
        );
        };

        export default UserProfile;

- So sánh giữa Context API và Redux Toolkit:
    - Context API thường được sử dụng cho các ứng dụng nhỏ hoặc khi chỉ cần chia sẻ vài giá trị đơn giản. Nó dễ sử dụng và ít boilerplate.
    - Redux Toolkit thích hợp cho các ứng dụng lớn hoặc khi bạn cần quản lý nhiều trạng thái và xử lý các side effects (ví dụ: gọi API, quản lý dữ liệu bất đồng bộ).
- Khi nào sử dụng cái nào:
    - Context: Khi bạn chỉ cần quản lý một vài trạng thái toàn cục hoặc chia sẻ dữ liệu giữa các component.
    - Redux Toolkit: Khi ứng dụng của bạn lớn và có nhiều trạng thái cần quản lý, hoặc cần các tính năng phức tạp hơn như xử lý dữ liệu bất đồng bộ, caching, hoặc thay đổi trạng thái theo nhiều cách khác nhau.
